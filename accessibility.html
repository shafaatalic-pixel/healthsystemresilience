Accessibility

Accessibility Statement

Last updated 25 July 2026

HSREP is committed to making hsraep.org usable by everyone, including people who rely on assistive technology. Accessibility is treated as part of the work, not an afterthought.

The standard we aim for

We build and review the site against WCAG 2.1 Level AA. We do not claim perfection, but we hold ourselves to that bar and fix gaps as we find them.

What is in place

  • Semantic HTML with a single main heading per page and a logical heading order.
  • Text alternatives (alt text) on all meaningful images.
  • A skip-to-content link and keyboard-navigable controls on every page, with visible focus outlines.
  • A two-tier colour system tuned for WCAG AA contrast; we are completing that calibration across every component.
  • Responsive layouts that reflow cleanly from desktop to phone, at readable type sizes.
  • Lazy-loaded media so pages stay responsive, and descriptive link text with labelled form fields.

Known limitations

In the interest of honesty:

  • Some infographics and data visualisations carry information visually. Where we can, we pair them with text, and the full methodology and dataset behind the figures are already public, but a few remain primarily visual. If one is unclear, ask us and we will send the underlying numbers.
  • A dark theme is not currently enabled.
  • Some downloadable PDFs may not yet be fully tagged for screen readers.

Run into a barrier?

If something is hard to use, or you need content in an alternative format, email privacy@hsraep.org with the page and what happened. We will respond and fix what we can.

This statement references WCAG 2.1 AA and is reviewed as the platform grows.
